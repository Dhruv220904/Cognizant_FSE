# Week 8 — Version Control (GIT) Mandatory Hands-On

## 🎯 Objective
Five hands-on exercises covering the module's learning objectives: version control concepts,
clone/push/fork operations, and branch workflows.

Each exercise is a self-contained markdown walkthrough — the commands are meant to be run in a
scratch folder (or directly in this `Cognizant_FSE` repo) so you build real command-line muscle
memory rather than just reading about Git.

## 🧩 What's inside
```
GIT-Handson/
├── Exercise1-VersionControlBasics.md   -> init, add, commit, status, log
├── Exercise2-BranchingAndMerging.md    -> branch, checkout/switch, merge, conflict resolution
├── Exercise3-RemoteRepositories.md     -> remote add, push, pull, tracking branches
├── Exercise4-ForkingAndPullRequests.md -> fork, clone, PR workflow on GitHub
└── Exercise5-GitWorkflows.md           -> centralized, feature-branch, and Gitflow workflows
```

## ✅ Learning objectives covered
| Objective | Exercise |
|---|---|
| Explain version control concepts | Exercise 1 |
| Demonstrate branch, clone, push, forking operations | Exercises 1, 2, 3, 4 |
| Explain the concept of branch workflows | Exercise 5 |

## ▶️ How to use these
Each file has a "Try it" section with copy-pasteable commands. Run them in a throwaway
folder first (e.g. `~/git-practice`), then, once comfortable, apply the same operations to this
`Cognizant_FSE` repo (e.g. actually branching off `main` for a piece of hands-on work) so your
commit history shows the workflow in practice, not just a report about it.
